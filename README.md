# Auto Loot Plus Filter Companion

A standalone companion tool for **Auto Loot Plus** for **Enshrouded**.

It provides a graphical interface for managing the `ignoreItems=` filter used by Auto Loot Plus, including categories, subcategories, tiers, search, ignored-item overview, and reusable Filter Profiles.

## Requirements

- Enshrouded
- Auto Loot Plus by Dellemann
- Microsoft .NET 8 Desktop Runtime x64
- Microsoft Edge WebView2 Runtime

## What it changes

The Companion reads the current Auto Loot Plus:

- `mods\auto-loot-plus\items.txt`
- `mods\auto-loot-plus\config.txt`

Only the `ignoreItems=` entry is written by the Companion. Other Auto Loot Plus settings are preserved.
